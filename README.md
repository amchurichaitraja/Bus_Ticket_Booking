### About 
•	Developed a comprehensive Bus Ticket Booking System CMS application for users and service providers.
•	Designed a user-friendly interface with login and signup sections, allowing users to register and access the system.
•	Implemented functionalities for customers to book tickets, search for buses, and manage booking details, including payment processing.
•	Enabled service providers to manage bus details, schedules, and passenger information, while also tracking customer bookings.
•	Integrated an admin dashboard for managing and viewing user and service provider details and overseeing bus schedules.
•	Created a robust database schema with collections for buses, earnings, locations, notices, tickets, and users.
•	Ensured secure data handling and accurate record-keeping for transactions, bookings, and user information.
•	Implemented features for users to view and manage their booking history, and for admins to add providers and view bus schedules.
